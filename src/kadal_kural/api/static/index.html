      How each order is checked

      1. Hear. Gnani Prisma transcribes the trader's Tamil or Tanglish from 8 kHz audio.
      2. Understand. Tamil numbers and case endings are normalised, then buyer, item, quantity, unit and rate are matched to the catalog.
      3. Gate. If any part is below 82% confidence, or the price or quantity is implausible for the item, the trader is asked again.
      4. Credit check. The order's value is added to the buyer's balance; anything over the limit is held, not dispatched.
      5. Record and reply. The ledger gets a new entry (never an edit) and the answer is spoken back in Tamil. No AI model does the arithmetic.
